Convert to PDF in the browser (LibreOffice WebAssembly)

.doc .ppt .xls → PDF · License MPL-2.0 · The real LibreOffice engine compiled to WebAssembly. The document never leaves the browser; the PDF is shown with pdf.js.

Install: npm install @matbee/libreoffice-converter coi-serviceworker

Heavy: the engine is about 250 MB (downloaded once, then cached by the browser) and takes time to start. Desktop Chrome or Edge recommended. Phones may run out of memory. Used only for the old 97-2003 formats; .docx, .xlsx and .pptx already show well in the normal viewer (and .pptx export in this engine build hung in testing).
