Docs Viewer app

Open-source JavaScript library demos

Each page renders a sample file in the browser and shows the code that did it. Nothing is uploaded. Green border = recommended for production.

Which libraries are used

Green border = recommended for production. Those are the libraries the project actually uses. The others are alternatives for special needs.

Green (recommended, used inside Docs Viewer)

  • Docs Viewer component: the all-in-one wrapper
  • pdf.js: PDFs
  • docx-preview: Word
  • SheetJS CE: Excel and CSV
  • JSZip: PowerPoint
  • cfb: old Word .doc and PowerPoint .ppt (no separate demo page)
  • UTIF.js: TIFF scans

No green (optional alternatives)

  • mammoth + DOMPurify: use it instead of docx-preview only if you want clean text-style HTML without page layout.
  • ExcelJS: use it if you need cell styles (bold, colors, fonts). It only reads .xlsx, not .xls.
  • Papa Parse: only for CSV. SheetJS already handles CSV, so you need it only for very large or tricky CSV files.
  • Viewer.js: adds zoom, rotate, flip and pan for images. A plain <img> is enough to just show an image.
